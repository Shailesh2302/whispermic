Installation

Beta builds are signed. If OS warns "unknown developer", see per-OS steps below. No account needed — downloads are open to everyone.

Filenames above are what CI publishes per release — until the first release, build them locally; the links activate automatically once RELEASES_URL is set in js/config.js.

⬇ Get builds

Windows

1. Run .msi → Next → Finish
2. Launch WhisperMic (tray icon appears)
3. Allow Microphone when prompted
4. Click any text field, press Ctrl+Alt+D, speak.

macOS

1. Open .dmg → drag WhisperMic to Applications
2. First launch: right-click → Open (bypass Gatekeeper once)
3. System Settings → Privacy & Security:
   - Microphone → enable WhisperMic
   - Accessibility → enable WhisperMic  (required for typing!)
4. Relaunch app. Press Ctrl+Option+D.

Note: macOS uses Ctrl+⌥+D (Option = Alt).

Linux — pick your package

No published release yet, so there is nothing to download — build the packages yourself (one command, ~5 min first time), then install the file it produces.
# 1. one-time system deps (Debian/Ubuntu)
sudo apt update && sudo apt install -y libwebkit2gtk-4.1-dev libgtk-3-dev \
  libayatana-appindicator3-dev librsvg2-dev patchelf libasound2-dev rpm

# 2. build the installers (from repo root)
bun install
bunx turbo run build --filter=@whispermic/desktop
# outputs land in apps/desktop/src-tauri/target/release/bundle/{deb,rpm}/ + website/downloads/
# Option A — Debian / Ubuntu (.deb, recommended)
sudo apt install ./apps/desktop/src-tauri/target/release/bundle/deb/WhisperMic_0.1.0_amd64.deb

# Option B — Fedora / RHEL (.rpm)
sudo dnf install ./apps/desktop/src-tauri/target/release/bundle/rpm/WhisperMic-0.1.0-1.x86_64.rpm

Wayland: typing needs XWayland or ydotool portal. X11 works out of the box.

Offline models (optional, for local STT)

mkdir -p ~/.whispermic/models
cd ~/.whispermic/models
# tiny.en = fastest (~75MB), base.en = better (~145MB)
curl -L -o ggml-tiny.en.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-tiny.en.bin
# then in app Settings → Provider → Local

Build from source (developers — Turborepo)

git clone <repo> && cd dictation_app
bun install              # installs workspaces + turbo (single bun.lock)
bun run test             # runs all workspace tests via turbo
bunx turbo dev --filter=@whispermic/desktop   # hot reload overlay
bunx turbo run build --filter=@whispermic/desktop  # → apps/desktop/src-tauri/target/release/bundle/

# Rust only (no UI):
cd apps/desktop/src-tauri && cargo check && cargo run

Configure STT keys via env (see apps/desktop/.env.example):

STT_PROVIDER=deepgram
DEEPGRAM_API_KEY=dg_...
OPENAI_API_KEY=sk-...
