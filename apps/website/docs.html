Docs — how to use WhisperMic

Quick start (60s)

  1. Install from Install page, launch WhisperMic. Tiny mic appears top-right.
  2. Click any text field (browser, VS Code, Word) — leave cursor there.
  3. Press Ctrl+Alt+D → speak → watch words appear at cursor in real-time.
  4. Pause 3s → auto-stop + mic fades to dot. Press shortcut again anytime.
Grant Microphone + Accessibility (macOS) / Input permissions on first run, or typing won't work. See Install page.

How to use the product

  • Tiny overlay: drag it anywhere. Scroll on it = volume? No — scroll passes through. Right-click → Settings (provider, auto-hide delay, shortcut).
  • Push-to-talk: hold Ctrl+Alt+Space, release to finish. Best for passwords / short inserts.
  • Long dictation: toggle once, speak paragraphs. Say "new line" / "full stop" → converted to \n / . automatically.
  • Works everywhere: typing is OS-level (enigo), so the target app never needs a plugin.

Audio + text refinement

Before typing, refine.rs runs (<1ms, offline):

  • Noise gate via VAD — breath/clicks below threshold never reach STT.
  • Filler strip: um, uh, like, you know (configurable list).
  • Auto-capitalise sentence starts + "i" → "I".
  • Collapse 3+ spaces, fix space-before-comma, ensure end punctuation.
  • Voice commands: "new line"→↵, "tab"→⇥, "full stop/period"→., "comma"→,, "question mark"→?.

Dictionary, snippets, styles, history

Right-click the mic → Settings. Everything is stored offline in ~/.whispermic/ — no account, no cloud.

  • Dictionary: STT keeps mishearing a name or term? Add hears → writes (e.g. koober neties → Kubernetes). Applied to every utterance, case-insensitive, punctuation-safe.
  • Snippets: say a trigger phrase alone (e.g. "my email") and your saved expansion is typed instead. Whole-utterance only, so it never fires mid-sentence by accident.
  • Styles: Professional (caps + punctuation), Concise (also cuts hedges like "i think", "just", "really"), Casual (relaxed casing).
  • History: last 200 finished dictations, newest first. Click any entry to type it again at your cursor.

Privacy

  • Local mode: audio never leaves device.
  • Cloud mode: 1.5s PCM chunks TLS → provider only. No storage by us.
  • Auth tokens stored in OS keychain (Tauri stronghold in roadmap).

Troubleshooting

  • Nothing types: macOS → System Settings → Privacy → Accessibility → enable WhisperMic. Linux → Wayland: use XWayland or portal; X11 works natively.
  • No mic: Settings → Input device → pick correct. Check OS mic permission.
  • Laggy: switch to Deepgram or smaller local model; close resamplers; use wired mic.
  • Shortcut conflicts: change in Settings; avoid browser-reserved combos.
