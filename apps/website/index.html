How it works

Audio never touches the DOM. Everything hot-path runs in Rust.

1. Press shortcut
Global Ctrl+Alt+D or hold Ctrl+Alt+Space for push-to-talk. Overlay pops, mic opens.
2. Speak
VAD gates silence → 1.5s windows stream to STT → refine() polishes → enigo types at cursor.
3. Done → auto-hide
3s silence → stop + fade to dot. Your text stays where you dictated it.
mic (cpal 16kHz) → vad.rs (energy gate, 30ms frames)
  → stt.rs (streaming partials, ~300ms)
    → refine.rs (fillers, caps, punct.)
      → typer.rs (enigo key injection at cursor)
